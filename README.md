# TRIVERA 採用LP

建設会社 TRIVERA の採用LP（1ページ）。Claude Design のカンプ（PC 1440 / SP 390）をもとに実装。

## ファイル構成

- `index.html` … ページ本体（10セクション＋ヘッダー・フッター）
- `css/style.css` … スタイル。PC（1440基準）→ 中間幅（768〜1439）→ SP（〜767）の順に書いてある
- `js/main.js` … SPメニューの開閉、説明会／エントリーボタンでフォームの希望内容を自動選択、フォームの入力チェック
- `images/` … 画像（すべてカンプから切り出した仮素材）

## デザインのルール

- 色：チャコール `#292B29` ／ アイボリー `#F5F1E8` ／ オレンジ `#E76B35` ／ コンクリート `#B8B6AE`（`:root` の変数）
- フォント：見出し・本文 Noto Sans JP、英字ラベル・数字 Montserrat、手書きキャプション Klee One（Google Fonts）
- `.pc-only` / `.sp-only` で PC と SP の出し分け（改行 `<br>` にも使用）

## [仮] のまま残っているもの

- 写真：AI生成の仮素材（カンプから切り出したもの）。正式素材で差し替える
- FAQの回答、フォームの「希望内容」の選択肢
- フォーム送信：入力チェックと完了メッセージのみ。送信先は未設定
- 社員インタビュー、プライバシーポリシー、サイトポリシーのリンク先
- 数値はすべて課題資料上の設定（注記を残すこと）
